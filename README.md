# SafeLA – Data Analytics & Crime Prevention Dashboard

### About the Project
This project is part of the **DEPI (Digital Egypt Pioneers Initiative)**, Data Analyst Track.  
It focuses on analyzing crime patterns in **Los Angeles (2020–2025)** using open public data, with the goal of understanding and predicting **city safety hotspots**.

---

### 🎯 Objective
To identify the most critical crime zones, times, and factors affecting safety in Los Angeles, and use data-driven insights to propose strategies for crime prevention.

---

### 🧩 Project Workflow
1. **Data Collection:** Los Angeles crime dataset (2020–2025) from official open-data sources.  
2. **Data Cleaning & Preparation:** Removing nulls, unifying date/time formats, encoding categorical variables.  
3. **Exploratory Data Analysis (EDA):**  
   - Crime trends over time  
   - Most frequent crime types  
   - Hotspots by area and time  
   - Victim demographics  
4. **Predictive Modeling (ML):** Forecasting crime intensity and identifying potential future hotspots.  
5. **Visualization:** Interactive Power BI / Tableau dashboard highlighting patterns and insights.  

---

### 📊 Dashboard Ideas
- Page 1: Overview KPIs (total crimes, trend per year, crime rate per area)  
- Page 2: Crime Heatmap (LAT/LON visualization)  
- Page 3: Victim Demographics (Age, Gender, Race)  
- Page 4: Weapon Usage & Time of Day Analysis  
- Page 5: Forecasting Future Hotspots
